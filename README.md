# bike-buyers-excel-analysis
This project analyzes a dataset of 1,027 bike buyers using Microsoft Excel to understand customer purchasing behavior.
## Dataset
- Records: 1,027
- Features:
  - Gender
  - Marital Status
  - Age
  - Income
  - Education
  - Occupation
  - Home Owner
  - Cars
  - Region
  - Commute Distance
  - Purchased Bike

## Tools
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Functions
